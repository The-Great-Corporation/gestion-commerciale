# gestion-commerciale
Projet créé dans le cadre de The Great Bootcamp
Application en ligne de commande devéloppée en python pour la gestion d'une activité commerciale(suivi des produits, prix et stocks)
## fonctionnalités
- Ajout de produits avec gestion robuste des erreurs de saisie (try/except)
- Organisation du code modulaire(orientée object avec dataclasses)
- Tests unitaires atomatisés validés avec Pytest

'''bash
